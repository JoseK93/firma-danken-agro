Cómo instalar la firma

Gmail: Configuración ⚙ → Ver todos los ajustes → General → Firma → Crear nueva. Inserta el PNG descargado con el botón de imagen y selecciona «Tamaño original». Guarda los cambios.

Outlook: Configuración → Cuentas → Firmas (en Outlook clásico: Archivo → Opciones → Correo → Firmas). Crea una firma nueva e inserta el PNG descargado. Guarda.

Recomendado: utiliza «Descargar PNG» e insértalo como imagen. «Copiar firma» puede fallar o superar el límite de Gmail en algunos navegadores.

La firma final es una imagen: el texto no se puede seleccionar ni los teléfonos pulsar directamente. Algunos destinatarios bloquean imágenes externas o adjuntas. Comprueba el resultado enviando un correo de prueba desde Gmail y Outlook. La firma se descarga a 600 × 180 píxeles. En Gmail selecciona «Tamaño original».
